How Websites Work

Contexte

Dans ce laboratoire l'objectif était de comprendre le fonctionnement général d'un site web et les différents éléments qui permettent son affichage. Nous avons étudié les interactions entre le navigateur, le serveur et les technologies utilisées pour créer des pages web.

Ce laboratoire permet de mieux comprendre les bases du développement web et est une introduction aux concepts indispensables pour l'étude de la cybersécurité des applications web.

Ce que nous avons compris

Nous avons pu découvrir le rôle des langages HTML, CSS et JavaScript dans la création des pages web. Nous avons également étudié la manière dont les navigateurs communiquent avec les serveurs afin de récupérer et d'afficher les différentes ressources nécessaires au fonctionnement d'un site.

Ce laboratoire nous a permis de mieux comprendre les différentes étapes intervenant lors du chargement d'une page web et l'importance de ces mécanismes dans le fonctionnement des applications modernes.

Conclusion

Ce laboratoire a été intéressant car il nous a permis d'acquérir une meilleure compréhension du fonctionnement des sites web et des technologies qui les composent. Il a également renforcé nos connaissances sur les échanges entre le client et le serveur.

Cette activité constitue une bonne introduction aux technologies web et représente une étape importante pour la suite des apprentissages en cybersécurité, notamment dans le domaine de la sécurité des applications web.
