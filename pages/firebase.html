Déploiement avec Firebase

Contexte

Pour finaliser notre projet de SAE et rendre nos comptes-rendus accessibles à nos professeurs, nous devions mettre notre site en ligne. Nous avons utiliser Firebase Hosting, une plateforme de Google qui permet d'héberger des sites web statiques de manière sécurisée, rapide et gratuite. L'objectif était de passer d'un environnement de développement local à une infrastructure de production accessible partout.

Ce que nous avons compris (Le Tutoriel)

Nous avons compris que le déploiement sur Firebase se gère entièrement en ligne de commande via le terminal et se résume en quatre étapes clés :

  • L'installation : On installe d'abord les outils Firebase de manière globale sur la machine avec la commande npm install -g firebase-tools.
  • L'authentification : On connecte notre terminal à notre compte Google en tapant firebase login, ce qui ouvre une page de validation sur le navigateur.
  • L'initialisation : C'est l'étape cruciale où on configure le projet avec firebase init hosting. Pour coller à notre structure, il faut spécifier le point (.) pour indiquer que nos fichiers sont à la racine (et pas dans un dossier public). Il faut aussi configurer le projet en "Single-Page App" (MFA/SPA) : cette option demande à Firebase de rediriger toutes les requêtes vers notre index.html, ce qui est indispensable pour que notre script router.js puisse gérer les routes sans générer d'erreurs 404 lors du rafraîchissement d'une page.
  • Le déploiement : Une fois la configuration terminée, il suffit de lancer firebase deploy pour envoyer les fichiers sur les serveurs de Google et obtenir notre URL finale.

Conclusion

Firebase Hosting s'est avéré être un outil extrêmement efficace et parfaitement adapté à notre projet. Pour notre SAE DevOps, cette manipulation est une excellente introduction aux problématiques de mise en production et de serveurs web. Le flux de travail est très fluide : chaque fois que nous modifions notre code ou ajoutons un nouveau compte-rendu de room TryHackMe, il nous suffit de retaper une seule commande pour que le site en ligne se mette à jour instantanément.
