Web Basics

Contexte

Dans ce laboratoire TryHackMe, l'objectif était de découvrir les principes fondamentaux du fonctionnement du Web. Nous avons étudié les différents éléments qui interviennent lors de la consultation d'un site Internet ainsi que les échanges entre le navigateur et le serveur.

Ce laboratoire permet de mieux comprendre les bases du Web, qui sont essentielles pour appréhender les concepts de cybersécurité liés aux applications web.

Ce que nous avons compris

Grâce à cet exercice, nous avons pu découvrir le fonctionnement des requêtes HTTP, le rôle des navigateurs et des serveurs ainsi que les différents composants qui permettent l'affichage d'un site web. Nous avons également appris l'importance des protocoles utilisés pour les communications sur Internet.

Ce laboratoire nous a permis de mieux comprendre comment les applications web interagissent avec les utilisateurs et pourquoi il est important de connaître ces mécanismes afin d'identifier plus facilement d'éventuelles vulnérabilités.

Vidéo

Conclusion

Ce laboratoire a été intéressant car il nous a permis d'acquérir les connaissances de base nécessaires à la compréhension du fonctionnement d'un site web. Il a également renforcé notre compréhension des échanges entre les différents acteurs impliqués dans les communications sur Internet.

Cette activité constitue une bonne introduction aux technologies web et représente une étape importante pour la suite des apprentissages en cybersécurité, notamment dans le domaine de la sécurité des applications web.


Retour d'expérience
Le laboratoire a été rapide à faire et facile.
